## 所有者とスコープ

Rust では、値には所有者があります。所有者である変数がスコープを抜けると、その値は破棄されます。この規則によって、ガベージコレクタを使わずにメモリの解放タイミングを静的に扱えます。

```rust
fn main() {
    let name = String::from("Rust");
    println!("{name}");
}
```

`name` は `main` のスコープ内で `String` を所有します。`main` が終わると `String` も破棄されます。

## ムーブ

コピーされない値を別の変数へ代入すると、所有権は移動します。移動後の元の変数は使えません。

```rust
fn main() {
    let name = String::from("Rust");
    let moved = name;

    println!("{moved}");
}
```

`String` はヒープ上のデータを持つため、暗黙に深いコピーを作りません。`let moved = name;` の時点で所有者は `moved` になります。

## 借用

値を渡したいが所有権は移したくない場合は、参照を渡します。

```rust
fn len(value: &str) -> usize {
    value.len()
}

fn main() {
    let name = String::from("Rust");
    println!("{}", len(&name));
    println!("{name}");
}
```

参照を使うと、関数は値を読むだけで所有しません。呼び出し元は関数呼び出しの後も値を使えます。

## まとめ

所有権、ムーブ、借用は、Rust の安全性を支える基本規則です。文章中心のページでは、このように概念、短い例、要点を順に並べると読みやすくなります。
