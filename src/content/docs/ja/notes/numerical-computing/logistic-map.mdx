このページは、数式、Rust/Wasm、グラフ可視化を組み合わせたテーマ別ノートの例です。本文は通常の MDX として書き、計算に必要な Rust コードは本文中のコードブロックとして置きます。

## モデル

ロジスティック写像は、単純な漸化式から複雑な振る舞いが現れる離散力学系です。

$$
x_{n+1} = r x_n (1 - x_n)
$$

ここで $x_n$ は時刻 $n$ の状態、`r` は成長率を表します。`r` と `x0` を動かすと、Rust/Wasm で系列を再計算し、グラフを更新します。

```rust
//| id: logistic-map-note
//| title: ロジスティック写像のパラメータを動かす
//| run: reactive
//| crates: [doc-rust]
//| inputs:
//|   r: { type: range, label: r, min: 0, max: 4, step: 0.01, value: 3.2 }
//|   x0: { type: range, label: x0, min: 0, max: 1, step: 0.01, value: 0.2 }
//|   steps: { type: integer, label: steps, min: 10, max: 300, step: 10, value: 120 }
let points = doc_rust::logistic_series(r, x0, steps).map_err(|error| error.to_string())?;
let final_point = points.last().ok_or_else(|| "series is empty".to_owned())?;

println!("x_{} = {:.6}", final_point.n, final_point.x);
emit_line_plot!(&points, "n", "x");
```

## 読み方

`r` が小さい範囲では、系列は安定した値へ近づきます。`r` を大きくすると周期的な振る舞いが現れ、さらに大きくすると初期値に敏感な変化が見えます。

このようなページでは、数式でモデルを説明し、実行可能セルで読者がパラメータを動かし、グラフで結果を確認できる構成にすると理解しやすくなります。
