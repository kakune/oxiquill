このプロジェクトは、技術ノートを静的サイトとして公開するためのワークスペースです。本文は Starlight の Markdown/MDX で書き、必要に応じて Rust、Python、数式、Mermaid 図、画像、PDF を同じページに配置できます。

TypeScript のコンポーネント import やレイアウト実装を著者に要求しないことを重視しています。ノートを書く人は `src/content/docs` に英語ページを、`src/content/docs/ja` に日本語ページを追加し、コードセルや図は通常の fenced code block として記述します。

## できること

- Rust セルをビルド時に WebAssembly 化し、ブラウザ上で実行する。
- Python セルを Pyodide worker で実行する。
- KaTeX によるインライン数式とブロック数式を表示する。
- Mermaid のフローチャート、シーケンス図、状態遷移図を表示する。
- PNG、JPEG、PDF などのメディアを `public/media` から簡単に埋め込む。
- 英語をroot、日本語を `/ja/` とする多言語ドキュメントを作る。
- 任意の Rust helper crate をテストし、ノートのセルから再利用する。
- 生成物を静的 HTML と静的アセットだけにまとめる。

## 基本構成

```text
src/content/docs/
  index.mdx
  authoring.mdx
  templates.mdx
  interactive-rust.mdx
  math.mdx
  mermaid.mdx
  media.mdx
  ja/
    index.mdx
    authoring.mdx
    templates.mdx
    interactive-rust.mdx
    math.mdx
    mermaid.mdx
    media.mdx
  notes/
    rust-basics/
      ownership.mdx
    numerical-computing/
      logistic-map.mdx
```

任意の共有 Rust ロジックは `crates/` に置きます。リポジトリ root は Rust workspace ではありません。MDX 内の Rust セルはビルド時に抽出され、`src/generated/doc-runtime` の独立した Wasm crate と manifest に変換されます。`crates: []` のセルは helper crate を必要としません。生成物は編集せず、必要になったら `pnpm docgen` または build/test コマンドで作り直します。

## 最初に読むページ

- [執筆ガイド](./authoring/) は、ノートの追加方法とコードセルの書き方をまとめています。
- [テンプレート](./templates/) は、新しいページを作るときのひな形です。
- [実行可能セル](./interactive-rust/) は、Rust と Python の入力付きセルを確認できます。
- [数式](./math/) は、KaTeX の使い方を確認できます。
- [Mermaid](./mermaid/) は、図を本文に埋め込む例です。
- [メディア](./media/) は、画像とPDFを本文に埋め込む例です。
- [ロジスティック写像](./notes/numerical-computing/logistic-map/) は、数式、Rust/Wasm、グラフを組み合わせたノート例です。
