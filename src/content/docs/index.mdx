This project is a workspace for publishing technical notes as a static site. Pages are written with Starlight Markdown/MDX, and can mix prose, Rust, Python, math, Mermaid diagrams, images, and PDFs in the same document.

The authoring model stays deliberately simple. Writers add English pages under `src/content/docs`, Japanese translations under `src/content/docs/ja`, and use ordinary fenced code blocks for executable cells and diagrams.

## What It Supports

- Build Rust cells into WebAssembly and run them in the browser.
- Run Python cells in a Pyodide worker.
- Render inline and block math with KaTeX.
- Render Mermaid flowcharts, sequence diagrams, and state diagrams.
- Embed PNG, JPEG, PDF, and similar media from `public/media`.
- Serve English at the root routes and Japanese under `/ja/`.
- Test optional Rust helper crates and reuse them from notes.
- Produce static HTML and static assets for deployment.

## Project Shape

```text
src/content/docs/
  index.mdx
  authoring.mdx
  templates.mdx
  interactive-rust.mdx
  math.mdx
  mermaid.mdx
  media.mdx
  ja/
    index.mdx
    authoring.mdx
    templates.mdx
    interactive-rust.mdx
    math.mdx
    mermaid.mdx
    media.mdx
  notes/
    rust-basics/
      ownership.mdx
    numerical-computing/
      logistic-map.mdx
```

Optional shared Rust logic lives in `crates/`. The repository root is not a Rust workspace. Rust cells in MDX are extracted at build time and converted into an independent generated Wasm crate and manifest under `src/generated/doc-runtime`; cells with `crates: []` need no helper crate. Do not edit generated files directly; regenerate them with `pnpm docgen` or the build/test commands.
