---
title: 実行可能セル
description: 静的サイト上で動く Rust、Python、Haskell のセルを設定します。
---

実行可能セルは、先頭に metadata comment を持つ通常の MDX code block です。Oxiquill は生成時にその block を抽出し、runtime UI に置き換えます。

Rust セルは build 時に WebAssembly に compile されます。Python セルは browser の Pyodide worker で動きます。Haskell セルは build 時に WASI WebAssembly module に compile されます。3つの言語は同じ input metadata と run mode model を使います。

## セル metadata

metadata は code block の先頭に置いた、言語に対応する連続した option comment block でなければなりません。Rust は `//|` または `///|`、Python は `#|`、Haskell は `--|` を使います。source code が始まった後の option comment 風の行は source code のままです。

top-level では次の field だけを指定できます。

- `id`: `^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$` に一致する必須のページ内 ID。
- `title`: cell header に表示する string。default は `id`。
- `run`: `button`、`reactive`、`autorun`。default は `button`。
- `inputs`: input name から input definition への mapping。default は省略で、`autorun` では指定できません。
- `timeoutMs`: 正の integer で指定する millisecond の実行 timeout。default は `30000`。
- `showSource`: source の初期表示を決める boolean。default は `true`。
- `crates`: 重複のない空でない helper crate name。Rust 専用。
- `packages`: 重複のない空でない vendored Pyodide package name。Python 専用。

unknown field、dependency name の重複、scalar/collection type の誤り、未対応 package、存在しない helper crate があると、page、fence line、cell ID、field path を含む diagnostic で生成が停止します。Haskell セルは standard library の code のみ対応し、どちらの dependency field も使えません。

## run mode

- `button`: 読者が明示的に実行します。
- `reactive`: 初回表示時に実行し、input 変更時に再実行します。
- `autorun`: 1回自動実行し、その後も run button から再実行できます。

## 入力

対応 input type は `range`、`number`、`integer`、`text`、`textarea`、`checkbox`、`select`、`radio` です。

input name は cell 内の変数として使われ、`^[a-z][a-z0-9_]*$` に一致する必要があります。各 definition は `type`、`label`、`value`、`min`、`max`、`step`、`integer`、`options` だけを含む mapping です。

- `type` の default は `text`、`label` の default は input name です。
- default value は checkbox が `false`、数値 input が `0`、text input が空 string です。明示する value はその scalar type と完全に一致する必要があります。
- 数値の `min`、`max`、`step` は有限値で、`step` は正、`min` は `max` 以下、default は bounds 内でなければなりません。`integer` input、または `integer: true` の数値 input では value と constraint も integer にします。
- `select` と `radio` には string default と、value が一意な空でない option list が必要です。option は空でない string、または空でない string の `label` と `value` を持つ mapping です。default は option value のいずれかに一致させます。
- 数値専用 field を数値以外の control で使うことや、`select`/`radio` 以外で `options` を使うことはできません。

Rust または Haskell の予約語は安全な生成 binding に変換されます。変換後に衝突する name がある場合、生成は失敗します。

## Rust とグラフ

この Rust セルは helper crate を使い、slider が変わるたびに plot を再描画します。

```rust
//| id: logistic-rust
//| title: Calculate the logistic map with Rust
//| run: reactive
//| crates: [doc-rust]
//| inputs:
//|   r: { type: range, label: r, min: 0, max: 4, step: 0.01, value: 3.2 }
//|   x0: { type: range, label: x0, min: 0, max: 1, step: 0.01, value: 0.2 }
//|   steps: { type: integer, label: steps, min: 10, max: 300, step: 10, value: 120 }
let points = doc_rust::logistic_series(r, x0, steps).map_err(|error| error.to_string())?;

for point in points.iter().take(5) {
    println!("n={} x={:.6}", point.n, point.x);
}

emit_line_plot!(&points, "n", "x");
```

## Rust 入力 UI

`crates: []` のセルは helper crate に依存しません。この例では checkbox、select、radio input を使います。

```rust
//| id: rust-controls
//| title: Rust input UI
//| run: reactive
//| crates: []
//| inputs:
//|   include_bonus: { type: checkbox, label: include bonus, value: true }
//|   operation: { type: select, label: operation, value: double, options: [identity, double, triple] }
//|   style: { type: radio, label: style, value: compact, options: [compact, verbose] }
let base_score = match operation.as_str() {
    "triple" => 21_u32,
    "double" => 14_u32,
    _ => 7_u32,
};
let score = if include_bonus {
    base_score + 5
} else {
    base_score
};

println!("style = {style}");
println!("score = {score}");
```

## 複数 Rust helper crate

各 Rust セルは必要な helper crate を宣言します。名前は `crates/*` 配下の Cargo package name と一致させます。

```rust
//| id: rust-multiple-crates
//| title: Rust cell with multiple crates
//| run: reactive
//| crates: [doc-rust, doc-rust-text]
//| inputs:
//|   style: { type: radio, label: style, value: compact, options: [compact, verbose] }
let points = doc_rust::logistic_series(3.2, 0.2, 8).map_err(|error| error.to_string())?;
let final_point = points.last().ok_or_else(|| "series is empty".to_owned())?;

println!("{}", doc_rust_text::labeled_value("final step", final_point.n));
println!("{}", doc_rust_text::labeled_value("final x", format!("{:.6}", final_point.x)));
println!("{}", doc_rust_text::style_note(style.as_str()));
```

## Python 入力

Python セルも同じ input metadata を使います。input value は Python 変数として使えます。

```python
#| id: python-controls
#| title: Python input UI
#| run: reactive
#| inputs:
#|   scale: { type: number, label: scale, min: 1, max: 10, step: 1, value: 3 }
#|   label: { type: text, label: label, value: "sample" }
#|   enabled: { type: checkbox, label: include uppercase, value: true }
#|   method: { type: select, label: method, value: mean, options: [mean, sum, max] }
#|   style: { type: radio, label: style, value: compact, options: [compact, verbose] }
values = [1, 2, 3, 4]

if method == "sum":
    result = sum(values) * scale
elif method == "max":
    result = max(values) * scale
else:
    result = sum(values) / len(values) * scale

name = label.upper() if enabled else label
print(f"{name}: {method} = {result}")
print(f"style = {style}")
```

## Haskell 入力

Haskell セルは `--|` metadata comment を使います。input value は Haskell 変数になり、`putStrLn` や `print` の text output が結果 panel に表示されます。

```haskell
--| id: haskell-controls
--| title: Haskell input UI
--| run: reactive
--| inputs:
--|   factor: { type: integer, label: factor, min: 1, max: 5, step: 1, value: 3 }
--|   label: { type: text, label: label, value: sample }
--|   include_squares: { type: checkbox, label: include squares, value: true }
import Data.List (intercalate)

let base = [1 .. 4 :: Int]
let scaled = map (* factor) base
let displayed = if include_squares then map (\value -> value * value) scaled else scaled

putStrLn (label ++ ": " ++ intercalate ", " (map show displayed))
putStrLn ("total = " ++ show (sum displayed))
```
