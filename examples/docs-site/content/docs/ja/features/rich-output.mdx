実行可能セルは複数の typed output artifact を返せます。通常の `print` や `println!` も使えますが、より構造化された出力は共通 UI component で表示されます。

## 出力 type

Oxiquill は次の出力を表示します。

- stdout、stderr、display output の text。
- 構造化表示される JSON。
- sort 可能な column を持つ table。
- ECharts で render される chart。
- SVG、PNG、JPEG data から作る image。
- iframe 内の sandboxed HTML。

各 artifact は optional string の `id`、`title`、`caption` を持てます。worker から受け取る value は untrusted です。Oxiquill は renderer に渡す前に discriminator、field、plain-record structure、array shape、finite number、row width、MIME/base64 data、nested value を検証します。reject/render failure になった一つの artifact は local diagnostic を表示し、valid sibling を消しません。

## Artifact schema

| Kind    | Required field                                                 | Optional behavior                                                                                  |
| ------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `text`  | `stream: "stdout" \| "stderr" \| "display"`, `content: string` | `truncated` が bounded content を示します。                                                        |
| `json`  | `value`                                                        | cycle-aware formatting が BigInt を明示表現し、`truncated` が bounded serialized data を示します。 |
| `table` | `columns`、rectangular `rows`                                  | `rowCount` が original size、`truncated` が preview を示します。                                   |
| `chart` | 下記の valid `spec`                                            | oversize/invalid chart は local artifact error。                                                   |
| `image` | `mime: image/png \| image/jpeg \| image/svg+xml`、valid data   | `alt` が image alternative。                                                                       |
| `html`  | `html: string`, `sandboxed: true`                              | empty sandbox、no-referrer、下記の restrictive CSP で表示。                                        |

table column は `key`、`label`、optional `type` を持ちます。type は `string`、`number`、`integer`、`boolean`、`date`、`datetime`、`null`、`unknown` です。各 row は declared column count と正確に一致する必要があります。

## Chart schema

すべての chart spec は optional `title`、`xLabel`、`yLabel`、`xType`、`yType`、`legend`、`tooltip`、`dataZoom` を受け取ります。axis type は `value`、`category`、`time`、`log` です。未指定 axis は `value` が default ですが、bar 固有の x 軸は category です。heatmap は常に X/Y 両方が category axis であり、`xType` と `yType` は省略するか `category` にできますが、`value`、`time`、`log` は reject されます。

- `value` coordinate は finite number、`log` coordinate は 0 より大きい finite number です。
- `time` coordinate は finite epoch millisecond、または `YYYY-MM-DDTHH:mm:ss[.sss]Z` / `YYYY-MM-DDTHH:mm:ss[.sss]±HH:mm` 形式の ISO-8601 string です。calendar field と明示的な time zone も valid である必要があります。
- `category` coordinate は string または finite number です。heatmap axis に明示的な `xCategories` / `yCategories` array がある場合、coordinate は完全一致する listed string、または範囲内の safe な zero-based integer index に限定されます。index はその位置の category name に解決され、数値らしい新しい category name には変換されません。
- heatmap axis に明示的な categories array がない場合、finite number と string は `String(coordinate)` で正規化され、category は初出順に推論されます。`1` と `"1"` のように同じ label に正規化される値は一つの category を共有します。片方の axis だけ categories を宣言した場合も、X と Y は独立して正規化されます。

- `line`、`scatter`、`area`: optional `name` と `[x, y]` point を持つ `series[]`。
- `bar`: string `categories[]` と同じ length の numeric-or-null `values[]` series。
- `histogram`: `lower < upper` かつ count が non-negative の finite `[lower, upper, count]` tuple の `bins[]`。
- `heatmap`: optional string `xCategories`/`yCategories` array と、二つの category axis 上の finite `[x, y, value]` cell。

empty chart と equal point domain は valid です。heatmap は X/Y の category 数と heat value の範囲を示し、color scale には実際の heat value を使います。empty dataset だけは `0–1` を fallback にします。chart は textual title/caption と bounded accessible summary または equivalent table を提供します。equivalent がある場合、implementation canvas は accessibility API から隠されます。

chart は `html[data-theme]` の変更時も同じ ECharts instance を使い、ズーム・凡例・heatmap の色範囲の選択を保持します。一時的な renderer load failure の後には retry action を表示します。

### 軸範囲

`xMin/xMax/yMin/yMax` は有限数で指定し、min を max より小さくします。time の境界は epoch milliseconds、log は正数に限定します。category 軸に数値境界は指定できません。`xIncludeZero/yIncludeZero` は value 軸だけに指定できます。固定境界を優先しますが、bar・histogram・area の value y 軸はゼロを含む必要があり、この基準を無効にできません。

データ更新ではズームを保持します。境界やゼロ包含の変更・解除では全範囲へ戻し、凡例の選択は保持します。境界を省略すると自動範囲に戻ります。

Rust の line・scatter・bar・histogram マクロでは、データ引数の後ろに `options = &serde_json::json!({...})` を指定できます。ラベルと nested style を含む公開設定を指定でき、kind やデータは上書きできません。従来の位置引数 style も利用できます。[ロジスティック写像](../../samples/logistic-map/)は 0–1 の固定範囲を使います。

### ヒストグラムの区間

ヒストグラムの x 軸は数値軸です。各矩形は正確な `[lower, upper)` に対応し、負の境界、異なる幅、区間の空白を保ちます。重なるビンは拒否し、重ならないビンの入力順は変更しません。

既定の `mode: 'count'` は度数を高さにします。`mode: 'density'` は `count / (upper - lower)` を高さとし、面積が度数を表します。確率の総和を 1 にする正規化ではありません。y 軸名、tooltip、要約にモードを示します。value y 軸の基準はゼロ、log y 軸の基準は表示範囲の正の下端です。log は正の高さを必要とし、その矩形の面積は度数を表しません。

**移行:** 明示的な `xType: 'category'` は引き続き受理しますが、`value` に正規化します。新しいコードでは省略または `value` を指定してください。データの境界や度数は丸めません。

```rust
//| id: interval-histogram
//| title: Unequal-width histogram
let bins = [[-1.0, -0.5, 2.0], [0.0, 2.0, 4.0]];
emit_histogram!(&bins, options = &serde_json::json!({
    "mode": "density", "xLabel": "Measurement", "yLabel": "Frequency"
}));
```

### 表示の既定値

bar・histogram・area の value y 軸はゼロを含み、line・scatter はデータの範囲に合わせます。負の値もゼロを基準に描画します。log y 軸では軸の下端を基準にするため、棒の長さや塗りの面積を量として比較できません。**移行:** bar・histogram の `yType: 'time'` は拒否されます。量には value 軸、時刻には line・scatter を使ってください。

数値の表記は軸ごとの元データの範囲で決まり、ズーム中も変わりません。4 桁の年には桁区切りを付けず、大きな値や微小値には指数表記を使います。大きな値の近傍の狭い範囲では通常表記を維持します。目盛は値を区別できる精度を保ち、tooltip・色凡例・概要は有効 6 桁です。JSON と表の CSV の値は変更しません。負のゼロは `0` と表示します。

ゼロをまたぐ数値範囲では、データ値の絶対値が最大絶対値と浮動小数点イプシロンの積以下なら `0` と表示します。−1〜1 の範囲での `sin(π)` などの丸め誤差を除くためです。目盛と対数座標の微小値は維持します。時刻の目盛はズーム後の間隔に合わせて精度を変え、必要なミリ秒と日付を表示します。

**移行:** 時刻の目盛・tooltip・概要は、読者のローカル時刻ではなく UTC に統一されます。入力は引き続き epoch milliseconds またはタイムゾーンを明示した ISO-8601 文字列です。

題は図の上に一度だけ表示します。artifact と spec の題が異なる場合は spec の題を副題にします。HTML凡例はキーボード操作可能な系列ボタンを1ページ25系列で表示し、無名の系列には既定名を付けます。長い軸名・カテゴリ名は短縮し、軸名の全文は概要、カテゴリ名・系列名の全文は tooltip で確認できます。カテゴリ目盛は回転してから必要に応じて間引きます。長いカテゴリ名が多い図は分割してください。横棒の API はまだありません。

既定の 8 色は明暗テーマで共通です。既定背景に対し、隣接色（末尾から先頭への循環を含む）は通常視で OKLab 色差 15 以上、1・2・3 型色覚の模擬で 8 以上、各色と背景のコントラスト比は 3:1 以上を満たします。すべての系列の組合せの識別を保証するものではありません。色を再使用すると線種や散布図の記号が変わりますが、8 系列を超える図は分割を推奨します。独自パレットは著者が背景コントラストと色覚による違いを確認してください。heatmap は明度が単調に変わる単色相の連続色を使います。

## 出力の保持とグラフのスタイル

セルを再実行している間も、最後に成功した出力を表示し続けます。150ms の reactive debounce 中も同様です。更新中の表示はレイアウトを動かしません。再実行が失敗した場合は出力とエラーを併記し、**セルの実行を再試行**からやり直せます。キャンセルや入力不正でも出力を保持し、成功時に結果を置き換えてエラーを消します。出力の並びが動的に変わる場合は artifact に明示的な `id` を付けてください。重複 ID は出現番号で区別し、ID のない artifact は種類ごとの出現番号で対応付けます。

互換性のあるグラフは既存の canvas と ECharts instance を更新し、読者のズーム範囲を保持します。初回とデータ更新のアニメーションは既定で180ms、easing は cubicOut です。構造変更時は同じ instance の設定を置き換え、Starlight の light/dark 変更時は色と字体を更新し、読者の操作状態を保持します。グラフ更新が失敗しても最後の表示と概要を残し、局所的な再試行操作を表示します。OS の動作軽減設定は著者の animation 指定より優先され、グラフと更新表示のアニメーションを無効にします。

chart spec は次の optional `style` object を受け取ります。

```ts
interface ChartPalette {
  light?: readonly string[];
  dark?: readonly string[];
}
interface BaseChartStyle {
  height?: number;
  palette?: ChartPalette;
  showGrid?: boolean;
  animation?: boolean;
  animationDurationMs?: number;
}
interface LineChartStyle extends BaseChartStyle {
  lineWidth?: number;
}
interface ScatterChartStyle extends BaseChartStyle {
  symbolSize?: number;
}
```

line と area は `LineChartStyle`、scatter は `ScatterChartStyle`、bar・histogram・heatmap は `BaseChartStyle` を使います。

| Field                 | 許可される値と既定値                                                                                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `palette`             | `light` / `dark` の少なくとも片方を指定。各テーマに重複しない `#RGB` / `#RRGGBB` を1〜12色。heatmap は2色以上。短縮表記を展開し、大文字小文字を区別せず重複判定します。 |
| `showGrid`            | boolean。既定値は `true`。                                                                                                                                              |
| `height`              | 200〜800px の整数。既定値は 360px。heatmap は行数に応じて 240〜720px に自動調整します。                                                                                 |
| `animation`           | boolean。既定値は `true`。動作軽減設定を優先します。                                                                                                                    |
| `animationDurationMs` | 0〜2,000の整数。初回と更新の既定値は180。                                                                                                                               |
| `lineWidth`           | 1〜8の有限値。既定値2.25。line / area のみ。                                                                                                                            |
| `symbolSize`          | 2〜32の有限値。既定値7。scatter のみ。                                                                                                                                  |

palette は系列色を選び、heatmap では visual-map のグラデーションになります。片方のテーマが未指定なら、そのテーマの Oxiquill 既定色を使います。文字やグラフ周辺の色は Starlight に従います。不明な nested field、別の種類専用の field、生の ECharts options、callback、formatter、HTML は拒否します。style も通常の artifact byte 制限に含まれます。

既存の Rust macro signature はすべて利用できます。次の overload では末尾に JSON-serializable な style（例: `&serde_json::json!({ "lineWidth": 3 })`）を追加できます。

```text
emit_line_chart!(series, style)
emit_line_chart!(series, x_label, y_label, style)
emit_scatter_chart!(series, style)
emit_scatter_chart!(series, x_label, y_label, style)
emit_bar_chart!(categories, values, style)
emit_histogram!(bins, style)
emit_heatmap!(data, style)
emit_line_plot!(points, x_label, y_label, style)
```

macro は `spec.style` にシリアライズし、通常のグラフ検証が同じ制限を適用します。

### 数値の表示書式

value/log 軸には `style.xFormat` と `style.yFormat`、heatmap の色尺度には `style.valueFormat` を指定できます。目盛、ポインター、tooltip、要約に同じ設定を使います。category と time は専用の表示書式を保ちます。

各書式は `significantDigits`（整数 1–17）、`fractionDigits`（整数 0–20）、`unit`（文字列）、`notation`（`auto` または `si`）を受け付けます。2 種類の桁指定は併用できません。固定小数では末尾のゼロを保持し、小さい値がゼロに丸まる場合があります。負のゼロはゼロと表示します。未指定の書式は従来の規則に従い、設定を削除すると既定値へ戻ります。

単位は数値の後ろに表示し、軸名は `xLabel/yLabel` で指定します。SI はデータ範囲から共通の接頭辞（10⁻²⁴〜10²⁴）を選び、境界での丸めを考慮します。範囲外は指数表記に戻ります。元データを変更せず、callback、書式文字列、HTML、生の ECharts options は受け付けません。

```rust
//| id: formatted-voltage
//| title: Voltage measurements
let points = [[0.0, 1500.0], [1.0, 2400.0]];
emit_line_chart!(&points, "Time", "Voltage", &serde_json::json!({
    "xFormat": { "fractionDigits": 1, "unit": "s" },
    "yFormat": { "significantDigits": 3, "notation": "si", "unit": "V" }
}));
```

### 系列の ID とスタイル

XY・bar 系列には空でない一意の `id` を付けられます。実行ごとに同じ ID を使うと、並べ替えや改名後も系列の識別と凡例の選択を保持します。name は表示名であり、同名の系列も個別に選択できます。ID がなければ系列の位置で対応付けます。系列の追加・削除ではズームをリセットしません。既定の配色は記述順に従うため、系列の色を固定するには明示的に指定してください。

`series.style.color` は `#RGB/#RRGGBB` または `{ light, dark }` で指定し、少なくとも一方のテーマを含めます。未指定のテーマは chart palette を使います。line・area はさらに `lineType`（solid/dashed/dotted）、`step`（false/start/middle/end）、`smooth`（boolean）、`symbol`、`showSymbol` を使えます。scatter は色と記号、bar は色に対応します。記号は circle/emptyCircle/rect/triangle/diamond/none です。

smooth と step は同時に有効化できません。既定では平滑化せず、明示した線種・記号は配色循環の自動設定より優先します。showSymbol の指定は孤立点の自動検出より優先します。設定を削除すると既定値へ戻り、従来の chart 全体の lineWidth・symbolSize は引き続きサイズを指定します。

```rust
//| id: styled-series
//| title: Measured and reference series
let series = serde_json::json!([
    { "id": "measured", "name": "Measurement", "points": [[0, 1], [1, 2]],
      "style": { "color": { "light": "#3987e5", "dark": "#9085e9" }, "symbol": "diamond", "showSymbol": true } },
    { "id": "reference", "name": "Reference", "points": [[0, 1.5], [1, 1.5]],
      "style": { "lineType": "dashed", "step": "end" } }
]);
emit_line_chart!(&series, "Observation", "Value");
```

## Resource limit

producer は各 language worker 内で `postMessage` より前に limit を適用し、main thread でも bounded response を独立して再検証します。limit は UTF-8 byte 単位で、記載のものは run ごとに累積します。

| Resource                    | Limit                      | 超過時                                                      |
| --------------------------- | -------------------------- | ----------------------------------------------------------- |
| Artifact                    | 1 run 100個                | 追加 artifact を local reject。                             |
| stdout / stderr             | stream ごとに 1 MiB        | limit までだけ保持し、truncated として表示。                |
| Text、serialized JSON、HTML | artifact ごとに 1 MiB      | Text/JSON は `truncated: true` 可、HTML は reject。         |
| Table                       | 10,000 row、100 column     | bounded table は `truncated: true` と `rowCount` を使用可。 |
| Chart                       | 合計100,000 point/bin/cell | artifact-local error。                                      |
| Image                       | decoded 10 MiB             | artifact-local error。                                      |
| 全 validated output         | 1 run 16 MiB               | remaining budget を超える artifact を local reject。        |
| complete worker response    | 16 MiB                     | worker から page へ渡す前に後続 artifact を省略。           |
| worker error                | 16 KiB                     | UTF-8 message を truncate。                                 |
| artifact diagnostic         | 1件 8 KiB、1 run 64 KiB    | 各 limit 内で diagnostic を truncate。                      |

`truncated: true` を使えるのは text、JSON、table だけです。chart、image、HTML は黙って truncate しません。invalid/cyclic/over-deep JSON、ragged table、non-finite chart value、invalid base64/MIME pair、unsafe structural record が cell component を crash させることはありません。実行結果は `outputs` に統一され、ストリームのテキストと JSON 値を結果直下に重複して保持しません。

## グラフ画像

「データを表で表示」で、非表示の系列を含む元の値、ヒストグラムの両端と度数、heatmapの座標を確認できます。開いた時だけ変換し、最大10,000行を保持して総数と省略を表示します。表の並べ替え、ページ送り、CSV保存はキーボードで操作できます。系列ボタンは `aria-pressed` で選択状態を伝え、色・線種・記号を併用します。「ズームを戻す」は系列選択を保持して著者指定の全範囲に戻します。既存のグラフ要約も維持します。

「PNGを保存」「SVGを保存」は現在のテーマ、ズーム、系列の選択、heatmapの色範囲を反映します。PNGのピクセル数は描画領域の幅・高さの2倍で、SVGは同じ論理寸法です。背景と凡例を含み、animation、title、captionは含みません。一時rendererで保存するため、表示中のグラフは置き換えません。

著者はグラフの `style: { renderer: "svg" }` を指定できます。Rustのstyle引数やPythonの `display_chart` からも使えます。既定は `"canvas"` です。SVGは拡大・印刷向けのベクター出力ですが、大量データで常に高速とは限りません。印刷時は操作ボタンを隠し、グラフとcaptionを保持します。

## CSV copy の安全性

「全取得行をCSV保存」はページを跨いだ全保持行を、現在の並べ替え順で保存します。「表示中の行をCSVとしてコピー」は現在のページだけをコピーします。省略された結果では、報告された総行数ではなく取得済みの部分だけを保存します。ダウンロードはクリップボードを使わず、元の数値を保持します。

表の整数は、すべての整数を正確に表せる±9,007,199,254,740,991（`Number.MAX_SAFE_INTEGER`）までは全桁を表示します。それより大きな値と非整数は有効6桁とし、絶対値が `1e6` 以上または `1e-4` 未満なら指数表記にします。負のゼロは `0` と表示します。列内に絶対値10,000以上の数がある場合だけ桁区切りを付け、ページ間でも統一します。数値セルのtitle属性で元の値を確認できます。並べ替えとCSVには元の値を使います。

default table action は表示中の row を spreadsheet-safe CSV として copy します。最初の meaningful character が `=`、`+`、`-`、`@`、tab、carriage return の string header/cell には、RFC-style の comma/quote/line-break escape より前に apostrophe を付けます。この決定的な規則により、一般的な spreadsheet application が string data を formula として評価することを防ぎます。数値は変更しないため、実際の number `-42` は `-42` のままです。

## 実行結果の移行

**破壊的変更:** 実行結果は必須の `outputs` 配列だけを持ちます。結果直下の `stdout/stderr/value/plots` と公開型 `PlotSpec/LinePlotSpec` は削除されました。`JsonArtifact.value` と入力の `value` は引き続き利用できます。

以前は `outputs` が存在すると空配列でも旧フィールドより優先され、存在しない場合だけ stdout・stderr・value・plots の順で変換されていました。現在は旧形式だけの結果や配列以外の outputs を受け付けず、再生成を案内する診断を表示します。既存の outputs と併存する旧フィールドは無視します。

```typescript
const result = {
  outputs: [
    { kind: 'text', stream: 'stdout', content: 'Printed output' },
    { kind: 'text', stream: 'stderr', content: 'Diagnostic output' },
    { kind: 'json', value: { answer: 42 } },
    { kind: 'chart', spec: { kind: 'line', series: [{ points: [[0, 1]] }] } }
  ]
};
```

Rust の早期 return も artifact を明示してください。通常の出力には引き続き `println!` と `emit_*` を使えます。

```rust

    outputs: vec![OutputArtifact::Text(TextArtifact {
        stream: "stdout",
        content: "Early return".to_owned(),
        truncated: false,
    })],

```

任意 helper crate `doc-rust` の `PlotSpec/LinePlot/line_plot` も削除されました。`SeriesPoint` を `[f64::from(point.n), point.x]` に明示変換し、`emit_line_chart!` に渡してください。互換マクロ `emit_line_plot!` は残っています。

出力順は変わりません。Rust は stdout の後に emit 順、Python は stdout・stderr・display・自動 matplotlib 図・最終値、Haskell は stdout・stderr の順です。Python の最終値が None または空文字列なら暗黙の JSON 出力はありません。明示した JSON artifact の null・空文字列・false・0 は保持します。捕捉したストリームは display 呼び出しと交互には並びません。

## Python display helper

Python セルには display helper が含まれます。

- `display(value)` は value から JSON、table、image、HTML、text の出力を選びます。
- `display_json(value)` は JSON を出力します。
- `display_html(html)` は sandboxed HTML を出力します。
- `display_table(rows_or_dataframe)` は table を出力します。
- `display_image(data, mime)` は SVG、PNG、JPEG image data を出力します。

runtime は pandas DataFrame/Series、matplotlib figure、`_repr_mimebundle_`、`_repr_json_`、`_repr_html_`、`_repr_svg_`、`_repr_png_`、`_repr_jpeg_` などの rich representation も扱います。

**表示の移行:** matplotlib はセルごとに、グラフと共通の配色、sans-serif、淡い格子、上・右枠線なし、白背景を既定にします。暗色テーマでも白い紙面として表示します。セル内で `matplotlib.rcParams` を上書きするか、図の作成前に `matplotlib.rcdefaults()` を呼ぶと元の既定値に戻せます。

各セルはスタイル設定をリセットしてから既定値を適用するため、前のセルの `plt.style.use("dark_background")` は影響しません。格子線は `imshow` の画像にも重なります。写真やヒートマップで重ねたくない場合は `ax.grid(False)` を呼んでください。

図の題と軸名から画像の代替テキストを生成します。SVG は `svg.fonttype: 'none'` を使い、読者のブラウザのフォントで日本語を描きます。SVG が 10 MiB を超えると 150 DPI の PNG に切り替え、stderr に診断を出します。PNG で日本語を描くには Python 環境内のフォントが必要です。画像と実行全体の上限は維持し、PNG も大きすぎる場合は artifact エラーになります。

`display_chart(spec, *, id=None, title=None, caption=None)` は dict/list だけで全 6 種類の対話的チャートを出力します。pandas は不要です。spec の style と artifact の metadata を別々に指定できます。

`display_line(df, *, x, y, id=None, title=None, caption=None, style=None)` は DataFrame の列から line チャートを作ります。`y` は列名または重複のない列名リストです。行順・列順を保ち、総点数は 10 万点までです。x は数値・文字列カテゴリ・タイムゾーン付き日時、y は有限数値を扱います。日時は UTC の epoch milliseconds に変換します。欠損値、NaN、無限大、NaT、タイムゾーンなし日時は行位置と列名付きの出力エラーになり、有効な隣接出力は残ります。欠損の前後を線で接続しません。

```python
display_chart({
    "kind": "area",
    "series": [{"points": [[0, 1], [1, 2]]}],
    "style": {"animation": False},
}, id="area", title="Measurements", caption="Two samples")

import pandas as pd
values = pd.DataFrame({"time": [0, 1], "a": [1, 2], "b": [3, 4]})
display_line(values, x="time", y=["a", "b"], title="Two series")
```

## Rust output macro

Rust セルでは明示的な `emit_*` macro を使います。対応 macro:

- `emit_text!`
- `emit_json!`
- `emit_html!`
- `emit_svg!` と `emit_image_svg!`
- `emit_png_base64!` と `emit_image_png!`
- `emit_table!`、`emit_table_with_columns!`、`emit_records_table!`
- `emit_chart!`、`emit_area_chart!`、`emit_line_chart!`、`emit_scatter_chart!`、`emit_bar_chart!`、`emit_histogram!`、`emit_heatmap!`
- 互換用の `emit_line_plot!`。新規利用では座標を明示的に変換し、`emit_line_chart!` を使ってください。

`emit_chart!(spec)` は全 6 種類のチャートを受け付けます。`metadata = ...` の `id/title/caption` は artifact に属し、spec の `title/xLabel/yLabel` とは別です。表示タイトルは artifact の title を優先します。metadata の null は省略として扱い、それ以外のフィールドはその出力の診断になります。`emit_area_chart!` は line と同じ点列・系列、軸ラベル、末尾 style、`options = ...` 形式を使えます。既存マクロの引数形式は維持されます。不正な spec は有効な隣接出力を残して、その出力の診断として表示されます。

```rust
emit_chart!(serde_json::json!({
    "kind": "area",
    "title": "Spec title",
    "xLabel": "Time",
    "yLabel": "Value",
    "series": [{ "points": [[0, 1], [1, 2]] }],
    "style": { "animation": false }
}), metadata = serde_json::json!({
    "id": "measurements", "title": "Measurement report", "caption": "Two samples"
}));
emit_area_chart!(&[[0, 1], [1, 2]], "Time", "Value");
```

## 使い分け

短い説明文には stdout を使います。正確な構造を見せたい場合は JSON、比較可能な record には table、傾向や分布には chart、生成された視覚情報には image、他の artifact で表せない markup には sandboxed HTML を使います。

copy、sort、pagination、validation、running、completion、failure state は keyboard 操作可能で、localized English/Japanese label とともに announce されます。sandboxed HTML には意図的に script/same-origin permission がなく、referrer を送らず、external subresource を default で block します。正確な policy と trust boundary は [サポートとセキュリティ](/ja/guides/support-and-security/) を参照してください。

table interaction state は一つの execution result に限定されます。新しい result では page、sort、copy status を reset します。同じ result の rerender は互換性のある sort/page を維持しますが、row が減った場合は clamp 後の page を保存し、sort 対象 column が削除・置換された場合は sort を解除します。
